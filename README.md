# beautyscale.by

SEO и реклама для интернет-магазина https://beautyscale.by/.

- `CLAUDE.md`: правила работы (Claude Code читает автоматически).
- `MEMORY.md`: ключевые факты о проекте.
- `PLAN.md`: план работ и статусы.
- `DECISIONS.md`: решения и открытые вопросы.
- `docs/`: КП и выжимка истории.
- `reports/`: аудиты, отчёты, семантика.

Начало работы: `git clone`, открыть папку в Claude Code и написать «что дальше».
