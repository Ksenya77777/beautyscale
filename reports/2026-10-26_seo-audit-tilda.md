# SEO-аудит beautyscale.by: данные из Tilda и живой сайт

Дата: 26.10.2026. Кто: Claude (по просьбе Ksenya). Источники: Tilda (проект 7729007) через подключение, curl по живому сайту. Дополняет `reports/2026-10-15_seo-audit.md`. Яндекс Вебмастер, Search Console, Lighthouse не проверялись.

## Итог по структуре

- Опубликовано 33 страницы Tilda, в sitemap.xml 25 адресов, в sitemap-store.xml 310 карточек товаров (дублей URL нет).
- В каталоге 378 товаров. В 51 разделе каталога часть товаров скрыта (`off`), заголовки с префиксом «&amp;» это служебные позиции (пакеты, фольга, перчатки).
- Метрика (счётчик 95181901), GTM (GTM-PRF9RFX6), подтверждения Яндекса и Google, схема Store в head подключены.
- У H1 на главной в исходном HTML есть 1 тег: пункт 7 из первого аудита снимается.

## Что в порядке

- HTTPS включён, HTTP переадресуется на HTTPS.
- Canonical на главной, на `/shop`, `/hair` и на карточках заданы на себя.
- Title и description у страниц-категорий заполнены под запросы «купить в Минске».
- 25 URL в sitemap.xml совпадают с опубликованными страницами, служебные страницы в sitemap не попали.
- Alt-тексты товаров добавляются скриптом в head (`beautyscale-alt-fix`), для части товаров alt задан вручную.
- Ответ сервера 0,3-0,7 с.
- Яндекс Метрика (вебвизор включён) и GTM работают.

## Ограничения этого прохода

- Нет данных Вебмастера и Search Console (индексация, запросы, ошибки).
- Не измерялись Core Web Vitals; на главной остаётся видео на Dropbox 3840x2160 (пункт 3 первого аудита).
- Анализ внутренних страниц выборочный: `/`, `/shop`, `/hair`, одна карточка.
